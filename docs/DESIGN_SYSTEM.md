
# ANFA ATHLETICS — Design System

**Status:** Initial visual specification  
**Brand direction:** Raw Luxury · Minimal Industrial Technical  
**Primary collection:** FORGED 01

## 1. Design vision

ANFA ATHLETICS should look like a premium athletic apparel brand with a strong, recognizable visual identity.

The design should communicate:
- Strength and athletic performance.
- Precision and quality.
- Modern minimalism.
- Technical design.
- Premium but accessible products.

The experience must feel sophisticated, not cluttered or excessively futuristic.

The website should combine striking campaign photography with simple navigation, clear product information and effortless shopping.

## 2. Brand personality

The digital experience should be:

- Bold, but not aggressive.
- Premium, but not complicated.
- Minimal, but not empty.
- Technical, but easy to understand.
- Interactive, but fast and accessible.
- Distinctive, without sacrificing usability.

Avoid generic sportswear templates, excessive gradients, unnecessary glass effects, oversized rounded cards everywhere, and animations that slow down shopping.

## 3. Colour palette

These are the initial brand colours. Use them consistently and review them against the approved logo and campaign assets before finalizing the production design.

### Primary colours

**Stealth Matte Black**
- Hex: #17191B
- Role: Main brand colour, dark backgrounds and strong headings.

**Graphite**
- Hex: #26282A
- Role: Secondary dark backgrounds, navigation and elevated dark surfaces.

**Concrete Grey**
- Hex: #A5A8A8
- Role: Secondary elements, muted backgrounds and supporting information.

**Tactical Olive**
- Hex: #59614A
- Role: Selective accents, collection details and secondary actions.

**Industrial Taupe**
- Hex: #A69A87
- Role: Warm supporting accents and selected collection visuals.

**Clean White**
- Hex: #FFFFFF
- Role: Main light backgrounds and contrast against dark elements.

### Colour rules

- Use black, white and graphite as the visual foundation.
- Use olive and taupe selectively.
- Do not make every button or section a different colour.
- Avoid low contrast for text.
- Do not communicate availability, errors or success through colour alone.
- Use accessible text and control contrast.

## 4. Typography

Typography should feel confident, clean and contemporary.

### Main headings
- Use a bold sans-serif typeface.
- Keep large headings short and deliberate.
- Use strong size and weight contrast.
- Avoid decorative fonts.

### Body text
- Use a highly readable sans-serif typeface.
- Keep paragraphs easy to scan.
- Use comfortable line spacing.
- Avoid unnecessarily small text.

### Labels and technical information
- Use restrained uppercase labels where appropriate.
- Use consistent styling for size, colour, product information and technical details.
- Never use uppercase for long passages of text.

### Font selection

Choose a high-quality, web-compatible sans-serif font after reviewing available licensing and performance.

Use a consistent font system across the website. Test all supported languages, including Arabic, before approving a font for production.

## 5. Layout and spacing

The layout should create a sense of precision and calm.

- Use a consistent spacing scale.
- Align elements carefully.
- Leave sufficient room around important content.
- Keep product grids orderly.
- Use clear separation between content sections.
- Avoid placing too many cards inside other cards.
- Maintain consistent margins and page widths.

Large screens should take advantage of space without making text lines excessively long.

Mobile layouts should prioritize essential information and easy interaction.

## 6. Corners, borders and shadows

Use a restrained industrial style.

- Prefer square or slightly rounded corners.
- Use thin borders where they improve clarity.
- Use shadows sparingly.
- Avoid overly soft, inflated card designs.
- Use consistent corner styles across similar components.

Buttons, product cards, forms and navigation elements should follow the same rules.

## 7. Buttons and interactions

Create reusable button styles.

### Primary button
Used for the most important action, such as adding an item to the cart.

- Strong contrast.
- Clear action label.
- Comfortable click or touch area.
- Obvious hover, focus, disabled and loading states.

### Secondary button
Used for supporting actions.

- More restrained visual treatment.
- Clear border or background distinction.
- Consistent sizing and spacing.

### Text link
Used for navigation and less prominent actions.

- Clear, readable styling.
- Visible hover and keyboard focus states.
- Never rely on colour alone to distinguish important actions.

Each button should communicate what it does.

Avoid unnecessary animations or unclear icon-only controls.

## 8. Navigation and header

The website header should provide quick access to:

- ANFA logo.
- Main collections.
- Search.
- Customer account.
- Wishlist where appropriate.
- Shopping cart.

Keep the navigation visually clean.

The mobile menu must be easy to open, navigate and close.

The header must not cover important content or interfere with the shopping experience.

## 9. Homepage

The homepage should feel like entering the ANFA digital flagship store.

### Hero section
- Strong campaign imagery.
- A clear brand statement.
- Minimal supporting text.
- One primary action and, if needed, one secondary action.

### Collection presentation
- Give FORGED 01 a distinctive visual section.
- Display products through high-quality photography.
- Keep collection names and calls to action clear.

### Signature features
Introduce ANFA ID, Outfit Lab and virtual try-on through carefully designed sections.

Do not force visitors to create an account or use 3D features before shopping.

### Footer
Include clear access to contact information, customer support, policies, language controls and social channels.

## 10. Product pages

Product pages must prioritize the information needed to make a purchase.

Include:
- Product imagery.
- Product name and price.
- Colour and size selection.
- Stock availability.
- Size guide.
- Fit description.
- Material and care information when verified.
- Add-to-cart action.
- Shipping and return information.

Keep essential purchase controls accessible on mobile.

Product images should remain prominent, sharp and consistent.

## 11. Product cards

Every product card should use a consistent layout.

Display:
- Product image.
- Product name.
- Price.
- Available colours where appropriate.
- A clear route to the product page.

Use consistent image ratios and avoid mixing unrelated image styles.

Hover effects should be subtle and must not hide essential product information.

## 12. Motion and animation

Animation should improve the experience rather than distract from it.

Suitable uses include:
- Smooth menu transitions.
- Subtle product-image changes.
- Short page transitions.
- Small feedback animations after an action.
- Carefully optimized 3D interactions.

Rules:
- Keep animations fast and intentional.
- Avoid long loading transitions.
- Respect reduced-motion preferences.
- Never block checkout behind an animation.
- Ensure the site remains usable if an animation or 3D feature fails.

## 13. 3D and Outfit Lab visual direction

The 3D experience should feel like a premium technical fitting studio.

- Use clean backgrounds.
- Present the avatar clearly.
- Provide obvious rotation and viewing controls.
- Make garment and colour selection simple.
- Keep the interface uncluttered.
- Clearly distinguish available garment sizes.
- Show loading and failure states.
- Provide an alternative for devices that cannot handle the 3D experience.

The customer must always be able to return to ordinary product shopping.

## 14. Forms and customer accounts

Forms should be simple and readable.

- Use clear labels.
- Explain errors in plain language.
- Show required fields.
- Provide useful validation messages.
- Avoid requesting unnecessary information.
- Make password or email verification flows understandable.
- Keep customer profile navigation consistent.

The same visual language should apply to ANFA ID, account pages, saved outfits and the digital wardrobe.

## 15. Admin dashboard

The private administration dashboard may be more functional and information-dense than the public storefront.

Priorities:
- Clear navigation.
- Readable tables.
- Easy product editing.
- Visible stock information.
- Clear order status.
- Simple search and filters.
- Confirmations before destructive actions.
- Clear error and success messages.

It should use the ANFA identity but prioritize productivity over cinematic visuals.

## 16. Mobile-first usability

The website must work well on:
- Desktop.
- Tablet.
- Mobile phones.

Mobile priorities:
- Easy-to-tap controls.
- Readable text.
- Product images that fit the screen.
- Simple navigation.
- Clear size selectors.
- An accessible cart.
- A straightforward checkout.
- Optimized image and 3D performance.

Do not simply shrink the desktop layout. Rearrange it to suit mobile use.

## 17. Accessibility and languages

Plan for French, Arabic and English.

Requirements:
- Consistent page structure.
- Proper keyboard navigation.
- Visible keyboard focus.
- Appropriate text contrast.
- Descriptive labels.
- Accessible forms and controls.
- Alternative text for meaningful images.
- Right-to-left layout support for Arabic.
- Respect for reduced-motion preferences.

## 18. Performance

A premium design must also be fast.

- Optimize image sizes.
- Use modern image formats when suitable.
- Load nonessential content only when needed.
- Avoid unnecessary JavaScript.
- Keep third-party scripts to a minimum.
- Optimize 3D assets.
- Test mobile performance.
- Avoid loading large assets before they are needed.

A visually impressive website that feels slow is not an acceptable result.

## 19. Reusable design system

Build common components instead of styling every page independently.

Reusable components should include:
- Header.
- Footer.
- Buttons.
- Inputs.
- Product cards.
- Product grids.
- Size selectors.
- Colour selectors.
- Modal windows.
- Navigation menus.
- Notifications.
- Loading indicators.
- Error states.
- Empty states.

Use consistent design tokens for colours, spacing, typography and borders.

Avoid duplicated components that gradually develop inconsistent styles.

## 20. Rules for AI implementation

Every AI working on the design must:
1. Read this file before implementing visual changes.
2. Reuse existing components and design tokens.
3. Inspect existing styles before changing them.
4. Avoid redesigning unrelated sections.
5. Check desktop and mobile layouts.
6. Test hover, focus, loading, error and disabled states.
7. Avoid introducing unapproved colours and fonts.
8. Preserve accessibility and performance.
9. Report the files changed.
10. Never claim that a visual result has been tested without actually testing it.

## Final principle

Every ANFA page should feel like part of the same brand.

The design must combine premium visual impact with simple navigation, fast shopping, accessibility and consistency.
